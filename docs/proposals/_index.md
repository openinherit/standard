These documents describe potential future directions for INHERIT. They are not part of the current standard and carry no commitment to implementation.

**All proposals are tracked via [GitHub Issues](https://github.com/openinherit/standard/issues).** Start with an issue. A proposal document is only needed when an idea is too complex for an issue thread — typically when it involves trade-offs across multiple schemas, alternative design approaches, or worked examples. If a proposal document exists, it must link to its tracking issue via `github_issue` in the frontmatter.
